Исходные материалы:

  docs/input_sha256.json - SHA-256 файлов дистрибутива.

Запуск:
  В Windows открыть PCLAB/MDIAPP.EXE. Остальные DLL/BPL/INI/RTF должны
  находиться рядом с EXE. Создать эксперимент через Файл / Новый эксперимент,
  выбрать его в списке, ввести параметры из experiment_plan.json.
  Выбрать микросекунды, оставить «Опустошать кэш» включённым, нажать «Начать».
  После завершения сохранить BMP и RTF кнопкой «Сохранить».

Условия текущего запуска:
  Windows 10 x64 в QEMU 10.2.2 (TCG), 4 виртуальных процессора, 8192 МиБ RAM.
  Это демонстрационные измерения эмулируемой среды. QEMU не моделирует
  временное поведение аппаратного кэша. Значения CPUID описывают виртуальную
  модель процессора и не являются характеристиками аппаратного кэша Mac.
  По этим измерениям нельзя достоверно определить физические банки/строки
  DRAM, задержки аппаратного TLB или эффективность реальной предвыборки.
  Для аппаратных выводов требуется повторить опыты на физическом x86-ПК.

Исходный дистрибутив и методичка принадлежат их авторам.

Особенности предоставленного PCLAB:

  с __COMPAT_LAYER=WINXPSP3. Снимки и протокол находятся в evidence/.
  Он выполнен независимой 32-разрядной программой output/experiment4.exe.
  Это НЕ исправленный PCLAB, а воспроизведение алгоритма из методички.
  Исходник: scripts/experiment4.c; команда сборки указана в его начале.
  Запуск в VM: C:\user\ananyev\lr3\experiment4.exe.
  Получено 8 точек, по 5 повторов двух вариантов. Все 80 контрольных
  сумм проверены. Таймер QPC, медианы; перед каждым замером обход 32 МиБ.

  Опыт 2: подписи колонок RTF противоречат цветовым сериям BMP.
  В нормализованном CSV y1 = красная серия (вторая числовая колонка RTF),
  y2 = зелёная (первая). По легенде методички это список и массив, однако
  из-за ошибки экспорта такая привязка явно оговорена в отчёте.
  Печатный коэффициент 3,5926326E-250 недостоверен; пересчитан по таблице.

  Опыт 5: общий X в exp5.csv - номер обращения 0..31. Реальные разные
  смещения двух серий полностью сохранены в exp5_addresses.csv.
  Файлы *_raw_rows.csv сохраняют исходный порядок числовых строк RTF.
